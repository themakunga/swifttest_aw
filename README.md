Swift application and test project stored under [`tests_aw/`](tests_aw/).

## Open in Xcode

Open [`tests_aw/tests_aw.xcodeproj`](tests_aw/tests_aw.xcodeproj) to inspect the
application, unit-test and UI-test targets. Select an available scheme and a
compatible simulator or device before building or testing.

To list the project's schemes from a Mac with Xcode installed:

```sh
xcodebuild -list -project tests_aw/tests_aw.xcodeproj
```

The source, unit tests and UI tests are located in the sibling `tests_aw`,
`tests_awTests` and `tests_awUITests` directories inside `tests_aw/`.
